Notes

  • Hover over Nat.succ or trigger completion with Ctrl-Space.
  • Use F12 for definition and Shift-F12 for references.
  • Rename is on F2. Formatting is on Shift-Alt-F. Undo is on Ctrl-Z.
  • Open the embedded Rust card to expand an inline CodeMirror instance for Rust.
  • Edit the file to force diagnostics or signature help.
